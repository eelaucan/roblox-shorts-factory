# Drop a font here as `bubble.ttf` (gitignored)

A chunky, rounded, heavy sans reads most "Roblox chat". Good free options:
Fredoka, Baloo 2, Nunito ExtraBold, Luckiest Guy (display-only).

Path is set in `config.yaml` → `bubbles.font`. If the file is missing the renderer
falls back to Pillow's default bitmap font so the pipeline still runs.
